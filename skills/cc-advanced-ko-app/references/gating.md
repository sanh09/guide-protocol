# 수준 확인 절차 (고급, Claude 앱)

채팅 앱에는 학습자 컴퓨터에 남는 학습 기록이 없다. 그래서 질문과 확인 퀴즈로 판단한다.

## 1. 이미 확인했는지 보기

- 같은 채팅에서 수준 확인을 이미 마쳤거나, 같은 채팅에서 중급 과정을 방금 수료했다면 4번으로 간다.
- 학습자가 메시지에서 개발 경험이나 수료 여부를 이미 밝혔다면 그 질문은 건너뛴다.

## 2. 학습자에게 묻기

선택형 질문 도구가 있으면 쓰고, 없으면 번호를 붙여 텍스트로 묻는다.

> 고급 과정은 셸 스크립트와 JSON 설정, git을 직접 다루고, 훅처럼 명령을 자동으로 실행하는 기능도 배워요. 시작 전에 확인할게요.
>
> **1. 개발 경험이 있으신가요?** (코드를 직접 작성하고 터미널에서 git을 써 봤다면 "있음")
> ① 있음 ② 없음
>
> **2. 중급 과정을 마치셨나요?**
> ① 마쳤어요 ② 아직이에요
>
> **3. (개발 경험이 없다면) 기초 과정을 마치셨나요?**
> ① 마쳤어요 ② 아직이에요

판단:

| 개발 경험 | 기초 | 중급 | 다음 행동 |
|---|---|---|---|
| 있음 | 상관없음 | 상관없음 | 3번 중급 확인 퀴즈 |
| 없음 | 마쳤어요 | 마쳤어요 | 3번 중급 확인 퀴즈 |
| 없음 | 마쳤어요 | 아직 | 5번: 중급 과정으로 안내 |
| 없음 | 아직 | 상관없음 | 5번: 기초 과정으로 안내 |

개발 경험이 있으면 중급을 정식으로 마치지 않았어도, 확인 퀴즈를 통과하면 고급으로 갈 수 있다. 개발 경험이 없으면 기초부터 순서대로 가야 한다.

## 3. 중급 확인 퀴즈 (5문제, 4문제 이상 통과)

퀴즈 표시 도구가 있으면 그것을 쓴다. 없으면 텍스트로 내고, 정답은 학습자가 답한 뒤에 공개한다. 중급을 마친 학습자에게는 "채팅 앱에는 지난 수료 기록이 남지 않아서 짧게 확인해요"라고 한 줄로 설명한다.

1. allow에 `Bash(aws s3 ls)`, deny에 `Bash(aws *)`가 있다. `aws s3 ls` 실행은? ① 허용 ② 거부 ③ 물어본다 ④ 오류 → ② (deny → ask → allow 순서)
2. `git diff`로 시작하는 명령만 허용하고 `git diff-index`는 맞지 않게 하는 규칙은? ① `Bash(git diff*)` ② `Bash(git diff *)` ③ `Bash(git*)` ④ `Bash(*)` → ②
3. 사용자가 `/deploy`로 부를 때만 실행되고 Claude가 알아서 실행하지 않는 스킬을 만들려면 머리말에? ① `user-invocable: false` ② `disable-model-invocation: true` ③ `allowed-tools: none` ④ `model: haiku` → ②
4. `claude -p` 결과를 스크립트에서 파싱하려면? ① `--output-format json` ② `--verbose` ③ `--continue` ④ `--bare`만 쓰기 → ①
5. Claude가 Bash `rm`으로 지운 파일을 되돌리는 가장 믿을 만한 방법은? ① `/rewind` ② `/compact` ③ git에 미리 커밋해 둔 상태에서 복구 ④ `/clear` → ③ (체크포인트는 Bash 변경을 추적하지 않는다)

- **4문제 이상**: 통과. 4번으로.
- **3문제 이하**: 틀린 주제를 짚고 5번으로 간다(중급 과정, 필요하면 해당 레슨만 복습).

## 4. 시작

"확인됐어요. 고급 과정을 시작할게요"라고 한 줄로 말하고 레슨 목록을 보여 준다. 그다음 학습자의 목표를 묻는다.

## 5. 이전 과정으로 안내

고급 레슨은 진행하지 않는다. 다음을 친절하게 전한다.

- 이유 한두 문장 (예: "훅과 자동화는 명령을 자동으로 실행해서, 권한 규칙과 `-p`를 먼저 익혀 두어야 안전하게 쓸 수 있어요")
- 시작 방법: "이 채팅에서 'Claude Code 처음부터 알려주세요'(기초) 또는 'Claude Code 중급 시작할래요'(중급)라고 말하면 돼요." 해당 스킬이 이 계정에 없다면 https://github.com/sanh09/guide-protocol 에서 받을 수 있다.
- 퀴즈를 아깝게 통과하지 못했다면(3/5) 해당 중급 레슨만 복습하고 다시 확인 퀴즈를 볼 수 있다고 알려 준다.
