# 수준 확인 절차 (중급, Claude 앱)

채팅 앱에는 학습자 컴퓨터에 남는 학습 기록이 없다. 그래서 질문과 확인 퀴즈로 판단한다.

## 1. 이미 확인했는지 보기

- 같은 채팅에서 수준 확인을 이미 마쳤거나, 같은 채팅에서 기초 과정을 방금 수료했다면 3번으로 간다.
- 학습자가 메시지에서 이미 개발 경험이나 기초 수료 여부를 밝혔다면 그 질문은 건너뛴다.

## 2. 학습자에게 묻기

선택형 질문 도구가 있으면 그것을 쓰고, 없으면 번호를 붙여 텍스트로 묻는다.

> 중급 과정은 터미널과 Claude Code 기초에 익숙하다는 전제로 진행해요. 시작 전에 두 가지만 확인할게요.
>
> **1. 개발 경험이 있으신가요?** (코드를 직접 작성해 봤거나 터미널에서 git 같은 명령을 써 본 적이 있으면 "있음")
> ① 있음 ② 없음
>
> **2. (개발 경험이 없다면) 기초 과정을 마치셨나요?**
> ① 마쳤어요 ② 아직이에요

판단:

| 개발 경험 | 기초 수료 | 다음 행동 |
|---|---|---|
| 있음 | 상관없음 | 3번 시작 |
| 없음 | 마쳤어요 | 4번 기초 확인 퀴즈 |
| 없음 | 아직이에요 | 5번 기초 과정으로 안내 |

학습자가 "조금", "HTML만 해 봤어요"처럼 애매하게 답하면, 터미널에서 `cd`, `ls`, `git` 같은 명령을 써 봤는지 한 번만 더 묻는다. 써 봤다면 '있음'으로 보고, 아니면 '없음'으로 본다.

## 3. 시작

"확인됐어요. 중급 과정을 시작할게요"라고 한 줄로 말하고 레슨 목록을 보여 준다.

## 4. 기초 확인 퀴즈 (5문제, 4문제 이상 통과)

문제 번호(C-1~C-5)의 정답은 `quiz-answers.md`의 '수준 확인 퀴즈' 표에 있다. 학습자가 답을 보낸 뒤 채점할 때만 읽는다. 문제를 낼 때는 보기 순서를 섞고, 정답을 짐작하게 하는 표시나 예시를 넣지 않는다(SKILL.md의 퀴즈 규칙).

퀴즈 표시 도구가 있으면 그것을 쓴다. 없으면 텍스트로 내고, 정답은 학습자가 답한 뒤에 공개한다. 퀴즈를 내는 이유는 "채팅 앱에는 지난 수료 기록이 남지 않아서 짧게 확인해요"라고 한 줄로 설명한다.

1. **C-1.** 같은 작업을 계속하는데 대화가 너무 길어져서, 흐름은 유지한 채 공간을 확보하려면? ① `/clear` ② `/compact` ③ `/exit` ④ `/init`
2. **C-2.** Claude를 거치지 않고 터미널 명령 `ls`를 바로 실행하는 입력은? ① `/ls` ② `@ls` ③ `! ls` ④ `# ls`
3. **C-3.** 모든 프로젝트에 적용할 나만의 지침을 쓰는 곳은? ① `./CLAUDE.md` ② `~/.claude/CLAUDE.md` ③ `./CLAUDE.local.md` ④ `.claude/settings.json`
4. **C-4.** 팀원과 공유하지 않고 이 프로젝트에서 나만 쓸 설정 파일은? ① `.claude/settings.json` ② `~/.claude/settings.json` ③ `.claude/settings.local.json` ④ `CLAUDE.md`
5. **C-5.** 큰 작업 전에 Claude가 파일을 바꾸지 않고 계획만 보여 주게 하려면? ① plan 모드 ② acceptEdits 모드 ③ `/compact` ④ `/resume`

- **4문제 이상 정답**: 통과. 시작한다.
- **3문제 이하**: 틀린 문제의 주제를 짚어 주고 5번으로 간다. "이 부분만 기초 과정에서 복습하고 오시면 돼요"처럼 부담을 줄여 말한다.

## 5. 기초 과정으로 안내

중급 레슨은 진행하지 않는다. 다음 내용을 친절하게 전한다.

- 왜 기초가 먼저인지 한두 문장 (예: "중급은 터미널 명령과 설정 파일을 직접 다뤄서, 기초가 없으면 실습에서 막히기 쉬워요")
- 기초 과정 시작 방법: "이 채팅에서 'Claude Code 처음부터 알려주세요'라고 말하면 기초 과정이 시작돼요." 기초 스킬이 이 계정에 없다면 https://github.com/sanh09/guide-protocol 에서 받을 수 있다.
- "기초를 마치고 다시 오시면 바로 중급을 시작할게요"로 마무리
